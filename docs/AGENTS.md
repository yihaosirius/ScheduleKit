# docs/AGENTS.md

本目录的约定与项目根目录 [`../AGENTS.md`](../AGENTS.md) **同源**，不在此重复抄写——
两份文档一旦分叉，就会有人照着错的那份办事。

本目录下的文件分工：

| 文件 | 性质 | 什么时候更新 |
|---|---|---|
| `dev-trace.md` | **开发流水账**，每轮改动追加一条，字段固定 | 每次代码改动，同一次提交内 |
| `decisions.md` | **决策记录**（ADR 式），一项决策一条 | 做出设计决策时 |
| `api.md` | HTTP 接口规格，对外（快捷指令 / agent） | 接口变更时 |
| `shortcuts.md` | Apple 快捷指令搭建与排障 | 快捷指令流程变更时 |
| `widget.md` | Scriptable 小组件说明 | 组件变更时 |
| `deploy.md` | 部署与排障 | 部署方式变更时 |
| `push-notes.md` | 推送方案调研（本期未做） | 调研结论变化时 |
